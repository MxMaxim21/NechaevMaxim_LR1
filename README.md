# Calculator (WPF App)

Настольное приложение-калькулятор на платформе WPF (.NET Framework), поддерживающее базовый и инженерный режимы вычислений, а также ведение истории операций.

## Установка

1. Клонируйте репозиторий:
   git clone [https://github.com/MxMaxim21/NechaevMaxim_LR1.git](https://github.com/MxMaxim21/NechaevMaxim_LR1.git)
   cd NechaevMaxim_LR1

2. Откройте файл решения Calculator.sln в среде Visual Studio 2022.

3. Восстановите пакеты NuGet (включая библиотеку NCalc).

4. Соберите и запустите проект (F5 или Ctrl + F5).

## Использование

Обычный режим (Normal): выполнение базовых арифметических операций (сложение, вычитание, умножение, деление, расчет процентов).

Инженерный режим (Engineering): выполнение сложных математических операций (возведение в степень, извлечение квадратного корня, скобочные выражения).

История операций (History): просмотр списка ранее выполненных расчетов с возможностью очистки. История сохраняется локально в файл Calculator_history.log.

## Структура проекта

Models/: классы моделей данных.

Services/: слой бизнес-логики и работы с данными.

	Interfaces/: контракты сервисов (ICalculationService.cs, IHistoryService.cs) для обеспечения ослабления связи компонентов.

	CalculationService.cs: сервисный класс для парсинга и расчета математических выражений через NCalc.

	FileHistoryService.cs: сервисный класс для сохранения, чтения и очистки истории в локальном файле.

Views/: пользовательский интерфейс (WPF Pages).

	Normal.xaml / .cs: страница обычного калькулятора.

	Engineering.xaml / .cs: страница инженерного калькулятора.

	History.xaml / .cs: страница просмотра истории.

App.xaml / MainWindow.xaml: главная точка входа и окно-контейнер приложения.
